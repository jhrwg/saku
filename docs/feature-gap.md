# 折耳根记账 vs 同类软件：功能缺口清单

> 对比基准：随手记、鲨鱼记账、一木记账、口袋记账、MoneyWiz、MoneyThings、Beancount 类工具。
> 现状版本：v1.0.0（本地优先，无账号，无云同步）。
> 标记：`P0` 影响核心留存 / `P1` 明显提升体验 / `P2` 差异化或长尾。

## 一、已具备（对照用）

收支转账、多账户余额联动、多账本、二级分类、默认付款账户、预算（PRO）、搜索筛选、退款/报销标记（PRO）、统计仪表盘、近 6 月对比（PRO）、周期记账、通知与每日提醒、WebDAV 备份/恢复、CSV 导入导出、崩溃日志、数字/手势密码、指纹解锁（PRO）、8 套主题 + 自选色/背景（PRO）、检查更新与更新日志。

## 十一、小功能与细节逻辑（容易被忽略但很影响手感）

- 记完账后：回首页 / 留在记账页可配置；金额自动清零、分类保留；
- 连续记账时默认带上一次的账户和分类；
- 快速复制上一笔并改金额；
- 列表项左滑删除 + 撤销 toast；
- 长按账目出快捷菜单（复制、标记、移动账本）；
- 列表批量选择、批量改分类/删账本；
- 搜索历史与「上次筛选条件」记忆；
- 自定义账期起始日（比如每月 25 号算下月）；
- 跨月账单归属规则（按消费日 / 按还款日）；
- 金额四舍五入与分币处理（避免 0.1+0.2 误差）；
- 日期选择器支持周视图/快速跳年；
- 编辑金额后实时重算预算与结余；
- 删除最后一笔时的二次确认；
- 导入时字段顺序容错（按表头映射而非固定列）；
- CSV 导出防公式注入（`=cmd` 开头加前缀）；
- 时区处理（跨时区记录）；
- 网络失败时离线队列与重试；
- 通知点击直达对应页面（现在只打开首页）；
- 深色模式下图表颜色对比度；
- 手势返回与页面返回按钮行为一致；
- 双击返回退出确认；
- 「本月无记录」等空态插画；
- 大数值显示（万/亿单位缩写）；
- 复制账目到剪贴板（文本分享）；
- 账目搜索支持金额区间 `>100`；
- 分享账目为图片（社交场景）。

## 建议的下一版（按性价比排序）

1. **深色模式 + 跟随系统**（用户第一眼感知，改动集中在主题层）
2. **计算器键盘 + 金额记忆**（记账手感，直接提升留存）
3. **信用卡账单日/还款日提醒**（P0 缺口，复用现有通知能力）
4. **自定义时间区间 + 环比/同比**（报表刚需）
5. **回收站 + 删除撤销**（数据安全感）
6. **账单导入（微信/支付宝 CSV）**（差异化，但需要解析和去重）
7. **桌面小组件 + 长按快捷方式**（提升打开频次）

## 结构性缺口（需要慎重）

- **多设备实时同步**：现在是「整库备份 + 覆盖恢复」，真同步要服务端或 CRDT，工作量远超其他项；
- **家庭共享账本**：涉及成员、权限、冲突合并，建议放在同步之后。
